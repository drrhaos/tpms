# Чек-лист: двухуровневые тревоги на Teyes

Проверяет человек на магнитоле (эталон — Teyes CC3 + донгл AA55/CH340) после сборки на Windows (`./gradlew :app:testDebugUnitTest :app:installDebug`). Отмечайте результат и прикладывайте `logcat -s TPMS_RAW` / полный отчёт при сбое.

## 0. Подготовка
- [ ] Unit-тесты зелёные (`AlertEvaluatorTest`, `AlertPresentationTest`, `WheelCrossCheckTest`, `AlertSeverityTest`, `TripBoundaryTest`, `MonitoringHealthPolicyTest`, `SettingsExporterTest`).
- [ ] Онбординг: шаг уведомлений показывает «Разрешить окно тревоги»; кнопка открывает «Поверх других окон» (или Teyes-настройки / подсказку).
- [ ] «Проверка системы»: строки «Окно тревоги», «Громкость сигнала тревоги», «Уведомления о тревогах» зелёные.

## 1. Кнопки проверки (Настройки → Тревоги)
- [ ] «Проверить неисправность»: красное окно по центру поверх **навигатора**, **музыки**, **FrontApp**; рамка пульсирует; три импульса слышны **поверх музыки** (музыка приглушается, не останавливается) и **поверх радио** (FM/AM — отдельно!); «Понятно» закрывает окно.
- [ ] То же при голосовой подсказке навигатора — сигнал смешивается, не обрывает её.
- [ ] «Проверить внимание»: жёлтый баннер сверху, полоска 10 с, «×» закрывает, короткий «дин-дон».
- [ ] Громкость будильника на минимуме → сигнал всё ещё слышен; на 0 → «Проверка системы» красная.
- [ ] Если поверх радио сигнал не слышен — записать: нужна опция «будильник / навигация» (`USAGE_ASSISTANCE_NAVIGATION_GUIDANCE`).

## 2. Настоящие тревоги (откручивание / стравливание)
- [ ] Давление 65–80 % нормы → жёлтый баннер + сигнал, колесо жёлтое; уведомление в шторке не смахивается.
- [ ] Ниже 65 % → красное окно, сигнал каждые 30 с до «Понятно»; уведомление с кнопкой «Понятно».
- [ ] После «Понятно» окно возвращается через выбранный интервал (поставить 1 мин).
- [ ] Стравливание ≥ 0,3 бар за 10 мин (или флаг утечки AA55 ≥ 15 с) → «Быстрая потеря давления», красное окно.
- [ ] Дальнейшее падение на 0,25 бар после «Понятно» → окно и сигнал сразу.
- [ ] Второе колесо в неисправности → строка в том же окне, сигнал сразу.
- [ ] Подкачка до 70 % → окно уходит молча, уведомление становится «Вниманием».
- [ ] Перекос оси ≥ 0,4 бар при нормальных порогах → «Быстрая потеря давления».
- [ ] «Без звука 30 мин» в уведомлении «Внимания» глушит баннеры; неисправность всё равно звенит.

## 3. Мониторинг и датчики
- [ ] Выдернуть донгл при известных колёсах → через ~2 мин красное окно «Контроль давления не работает»; вставить — уходит.
- [ ] HID: снять батарейку одного датчика в движении → «Нет сигнала» через ~10 мин.
- [ ] AA55: мёртвый датчик (значение «замёрзло») → «Нет сигнала» через ~45 мин езды (записать, бывают ли ложные).

## 4. Экран, сон, процесс
- [ ] Экран выключен при неисправности → ни окна, ни звука; включили → окно и сигнал.
- [ ] Сон магнитолы с неисправностью → утром (новая поездка) окно и сигнал снова, даже если вчера «Понятно».
- [ ] Убить процесс (`adb shell am kill`) после «Понятно» → после START_STICKY окно не возвращается до напоминания.
- [ ] Android 14+ (телефон): смахнуть уведомление тревоги → возвращается сразу без звука.
- [ ] **Камера заднего хода** при красном окне: окно закрывает изображение? (записать — если да, нужна пауза окна на время камеры).
- [ ] Без разрешения «Поверх других окон» → неисправность показывается липким heads-up (full-screen intent) со звуком.
