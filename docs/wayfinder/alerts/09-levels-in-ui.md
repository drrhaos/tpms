## Question

Сейчас цвет колеса следует `AlertSeverity` (норма / WARNING жёлтый / ALERT красный / нет данных серый). С уровнями [01](01-severity-classification.md) и окнами [06](06-alert-window-look.md):

- Цвета и подписи «Внимания» и «Неисправности» на главном экране (колесо, строка показаний, шапка, плашка тревоги с «Понятно» из [05](05-alert-lifecycle.md)), в виджетах, плавающем оверлее и постоянном уведомлении — совпадают ли с окнами.
- Новый тип `PRESSURE_DROP`: короткая подпись, карточка, совет, текст уведомления.
- «Мониторинг не работает» в шапке и виджете.
- Состояние «подтверждено, ждём напоминания» — видно ли где-то.

## Resolution

Решено агентом по поручению drhaos («выполни все сам»), 2026-11-17.

- Цвета везде (главный экран, виджеты, оверлей, постоянное уведомление) — из уровня: «Внимание» жёлтый, «Неисправность» красный (`AlertSeverity` выводится из уровня), как в окнах. Следствие: давление 65–80 % теперь жёлтое (раньше красное).
- `PRESSURE_DROP`: короткая подпись «УТЕЧКА» / «DROP», карточка «Быстрая потеря давления», совет «Сбросьте скорость, остановитесь и осмотрите шину», текст уведомления «Быстрая потеря давления».
- «Мониторинг не работает» — в шапке, как сейчас (`monitoringOffline`); красное окно и уведомление — по [05](05-alert-lifecycle.md).
- Плашка тревоги на главном экране при неподтверждённой неисправности получает кнопку «Понятно»; после подтверждения кнопки нет.
